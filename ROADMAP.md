# Roadmap

ArchiveLoom is built in small, verifiable stages. Dates are intentionally not promised.

## 0.1 — Foundation

- [x] Adapter protocol and plugin discovery
- [x] Direct URL and collection manifest adapters
- [x] Cross-platform environment and storage diagnostics
- [x] Fixed progress UI, state, locking, verification, bounded retries
- [x] English and Japanese documentation
- [x] Validate the first hosted CI run on macOS, Windows, and Linux runners

## 0.2 — Production hardening

- [ ] Persist ETag and Last-Modified before resuming direct files
- [ ] Signed-URL refresh hooks for site adapters
- [ ] Segment-aware HLS resume mode
- [ ] Structured JSON Lines event output
- [ ] Configuration files and secure credential references
- [ ] More locale catalogs and translation contribution tooling

## 0.3 — Distribution

- [ ] Reproducible standalone binaries for macOS, Windows, and Linux
- [ ] Checksums, provenance attestations, and signed release artifacts
- [ ] PyPI trusted publishing
- [ ] Homebrew, Scoop, and winget packaging proposals

## 1.0 — Stable adapter API

- [ ] Versioned adapter compatibility contract
- [ ] Stable state and manifest schemas
- [ ] Maintainer-reviewed reference adapters
- [ ] Documented deprecation policy

Propose changes through a feature request. Roadmap items are not guarantees.
