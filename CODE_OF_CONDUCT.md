# Code of Conduct

ArchiveLoom is a technical community where people should be able to contribute without harassment or intimidation.

## Expected behavior

- Be respectful, patient, and specific.
- Critique code and ideas, not people.
- Welcome contributors across languages, experience levels, identities, and locations.
- Protect users' privacy and credentials.
- Accept maintainers' decisions about legal, security, operational, and project-scope risk.
- Correct mistakes openly and without retaliation.

## Unacceptable behavior

- Harassment, threats, discrimination, stalking, or sexualized attention
- Publishing private information or credentials
- Pressuring contributors to bypass DRM, authentication, access controls, or platform restrictions
- Deliberately overwhelming sites, CI, maintainers, or issue trackers
- Impersonation, deceptive attribution, or plagiarism
- Repeated disruption after a maintainer asks for a behavior to stop

## Enforcement

Report conduct concerns privately through the repository owner's GitHub profile contact method. Include links or screenshots when safe. Maintainers may edit or remove content, lock threads, reject contributions, temporarily restrict participation, or permanently ban participation.

Reports are reviewed as privately as practical. Retaliation against a reporter is itself a violation.

## Scope

This code applies in ArchiveLoom repositories, issues, pull requests, discussions, documentation spaces, and public interactions where someone represents the project.
