# ArchiveLoom brand assets

- `logo.svg` — production horizontal wordmark used by the README.
- `logo-mark.svg` — scalable square mark for avatars and package art.
- `logo-concept-source.png` — ImageGen exploration retained as source provenance.
- `logo-concept-transparent.png` — chroma-keyed copy of the exploration.

The production SVGs were redrawn as compact, accessible vector assets based on the generated exploration. They use three woven ribbons to combine the ideas of collection, ordering, and archiving.

## Generation record

Mode: OpenAI built-in image generation.

Prompt used for the exploration:

> Create a polished flat vector-style logo concept for an open-source cross-platform CLI named ArchiveLoom. Show three woven ribbons in indigo, cyan, and coral forming a downward download/archive arrow into a tray. Minimal geometric construction, strong silhouette, no text, no letters, no mockup, centered, generous padding, chroma-green background for clean transparency removal, suitable for a GitHub avatar and terminal-tool brand.

Do not use the generated PNG as an application icon without reviewing it at small sizes. Prefer the production SVG mark for releases.
