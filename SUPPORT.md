# Support

## Where to ask

- **Bug report:** use the bug issue form with sanitized diagnostics.
- **New site:** use the adapter request form.
- **New behavior:** use the feature request form.
- **Security issue:** follow [SECURITY.md](SECURITY.md), not a public issue.
- **Usage question:** open a GitHub Discussion when Discussions are enabled.

## Include this diagnostic information

```console
archiveloom --version
archiveloom doctor --output /your/output/path
ffmpeg -version
ffprobe -version
```

Remove usernames, credentials, signed query strings, cookies, private URLs, and personal file paths before posting.

## Scope

Maintainers can help with ArchiveLoom itself. They cannot provide legal advice, obtain access to restricted media, bypass DRM or authentication, or guarantee continued access to third-party sites.
