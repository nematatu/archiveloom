# Maintainers

ArchiveLoom follows a lightweight maintainer model while the project is young.

## Current maintainer

- `@nematatu` — project direction, releases, security triage

## Becoming a maintainer

Regular contributors may be invited after demonstrating sustained, constructive work across code review, documentation, testing, or adapter maintenance. Maintainer access is never required to make a meaningful contribution.

## Release policy

- Semantic Versioning is used after `0.1.0`; before `1.0`, minor versions may contain breaking changes.
- Every release must pass the supported-OS CI matrix and package build checks.
- Release notes must identify breaking changes, security fixes, and adapter compatibility changes.
- PyPI publishing and GitHub release publication require a protected environment and maintainer approval.
